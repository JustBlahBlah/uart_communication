## Навігація файлами

* **`main.c`**

  Основний файл вихідного коду. Реалізує ініціалізацію UART за допомогою POSIX API та termios, буферизацію символів, логіку зміни регістру символів і обробку сигналів SIGINT та SIGTER для коректного завершення роботи застосунку.

* **`makefile`**

  Файл конфігурації системи збирання. Підтримує локальну компіляцію, кроскомпіляцію за допомогою змінної CROSS\_COMPILE, а також автоматичне віддалене розгортання та встановлення застосунку через SSH за допомогою команд make deploy і make install.

* **`uartecho.service`**

  Файл конфігурації служби systemd. Використовується для встановлення застосунку як фонового демона на цільовому пристрої. Забезпечує автоматичний запуск застосунку під час завантаження системи та його повторний запуск у разі аварійного завершення роботи.

* **`Report.md`**

  Звіт про проєкт, у якому описано апаратну конфігурацію, перевірку UART за допомогою з'єднання Loopback, програмну реалізацію та етапи розгортання застосунку.

* **`.clang-format`**

  Файл конфігурації форматування коду, який забезпечує дотримання єдиного стилю оформлення вихідного коду.

* **`echo_20261110_193852.log`**

  Приклад журналу роботи застосунку. Містить часові мітки та вміст отриманих повідомлень.

## Швидкий початок роботи

### 1. Збирання проєкту

Для кроскомпіляції застосунку під 64-бітну версію Raspberry Pi виконайте на хост-комп'ютері таку команду:

```bash
make CROSS_COMPILE=aarch64-linux-gnu-
```

### 2. Розгортання та встановлення

Для автоматичного копіювання виконуваного файлу та служби systemd на Raspberry Pi з подальшим увімкненням автоматичного запуску демона виконайте:

```bash
make CROSS_COMPILE=aarch64-linux-gnu- install PI_HOST=192.168.0.106 PI_USER=pi
```

Під час виконання команди може знадобитися ввести пароль SSH віддаленого користувача.
